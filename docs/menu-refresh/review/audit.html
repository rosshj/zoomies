Menu audit

October 1, 2026 · Latest direction reviewed from ea95c66 on menu-refresh.

The core race and garage flow is coherent. This pass brings Collection, cups, and utility surfaces into the newer system, fixes focus after a Collection purchase, and extends the visual audit to deeper menus.

Browse the current screenshot gallery · Layout measurements

Direction used for this review

  • Home → Race setup; mode comes first, with focused pickers returning to their caller. Garage is the single entry for changing the racer.
  • Solid topbars without eyebrow headings. Shared indigo controls, cream choices, gold primary actions, consistent rounded corners and spacing.
  • Colourful preview cards, square edge-to-edge cat/kart imagery, track scenery plus the yellow outline. The menu's rotating track continues behind browsing and editing.
  • Summary-first studios, scrolling inside drill-ins, fixed primary/back actions, and stable previews. Lists may scroll; essential actions must remain reachable.
  • Portrait and landscape are composed independently. Preserve safe-area space, controller/keyboard access, saved choices, and guest-seat isolation.

Changes made in this audit

  • Collection: reused the actual racer card component, including square full-bleed art, lock/equipped indicators and compact status. Removed the old nested image border and long unlock descriptions from tiles. Full requirements and purchases use the same detail dialog as the cat/kart selectors.
  • Collection navigation: restored focus to the purchased card after rerender; cup rewards close Collection before opening cup selection. Owned items still equip directly.
  • Collection header and Awards: moved currency beside Close, used the shared indigo surface, made trophies a balanced two-column portrait grid, and improved award text contrast/spacing.
  • Cups: replaced bordered icon boxes with a coloured edge-to-edge icon panel and cream copy, using the softer palette established by Mode. Kept race count and reward information.
  • Settings: category controls now use the standard segmented-container height. Save data has consistent naming and a full-width Restore action below equal-width Copy/Paste actions.
  • Help and naming: removed legacy purple gradients/outlines from utility cards and added proper inset space to the name picker. Removed the redundant Pause eyebrow.
  • Audit tooling: scoped Race setup measurements to its visible preview, expanded detail-screen coverage, and kept the gallery tied to captures from the current run.

Recommended next priorities

  1. Dedicated Versus player drill-in. The current player rows and missing-controller messages are denser than the solo summary-first setup.
  2. Simplify Display settings. Keep current values visible, move long explanations into the corresponding choice screen, and avoid presenting every control at once.
  3. Improve track-change feedback and loading. Bundled thumbnails make browsing immediate; selecting a new track still reloads and builds a 3D world. Profile that path before promising a speedup.
  4. Consolidate menu styling. The stylesheet still has layers of historical overrides. Promote the settled card, toolbar, modal and spacing patterns into shared rules so future edits do not drift.
  5. Device validation. Test iOS safe areas/keyboard/scrolling, physical gamepad navigation and Steam Deck. The segmented container intentionally stays button-height; its inset segment hit areas deserve a real touch pass.
