The desktop app: the same game with local split screen for 2–4 players (controllers + keyboard on one screen), ready for the Deck's controls and screen.

⬇  Download for Steam Deck / Linux .zip · x86_64 · ~110 MB
Install on Steam Deck (one-time, ~5 minutes)
  1. Hold the power button → Switch to Desktop, and download the zip with the browser (or copy it over on a USB stick).
  2. Extract it somewhere like ~/Zoomies (right-click → Extract).
  3. Open Steam (still in Desktop Mode) → Games → Add a Non-Steam Game → Browse → pick zoomies-desktop from that folder.
  4. Switch back to Gaming Mode and launch it from your library. In the game's controller settings, pick the Gamepad template. Tap any button if the menu cursor doesn't show at first.

Updating later = replace the folder contents with a newer zip. Launching from a terminal instead of Steam? Add --no-sandbox.
